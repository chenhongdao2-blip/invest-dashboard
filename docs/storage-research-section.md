# AI / 存储研究专题

## 入口与范围

- 导航：AI 人工智能 → 存储；稳定路径 `/AI_Storage`。
- `a2_ai_overview.py` 将旧DRAM大图位置改为专题跳转，避免两套图并存。
- 延续原版暖底及紧凑研究图。历史文字取消截断，窄屏横向滚动。
- 114个研究实体、81个来源记录、24技术节点/36关系、三张表、四组分歧、两个五步场景、18个财务期间。
- 两个本地供应商审计/探针来源未公开。其余只在本地存在的阅读底稿无在线下载链接，保留来源名称及证明范围。

## 实现

`app/lib/storage_research_panel.py` 将 `app/assets/storage_research/` 的HTML、CSS、JS及四份JSON装成单一 `st.iframe` 文档。历史图用子文档联动；字体和ECharts复用已有 `app/static/`。资源URL保持相对路径，兼容Streamlit Cloud的代理前缀。无需8768服务、数据库迁移、新依赖或任何新secrets。

针对srcdoc使用继承的base URL来源校验，仍同时核对消息发送窗口；不放宽为任意来源。内部章节锚点在文档内滚动，不跳转为嵌套Streamlit应用。研究详情保留固定可见的滚动视口。

## 更新方式与发布边界

```
python jobs/export_storage_research.py --source /path/to/reviewed/local/preview
python -m pytest tests/test_storage_research.py -q
```

导出是显式白名单：5个界面文件、4个结构化JSON及manifest。不会复制evidence目录、报告、全文、供应商原始返回、会话记录、账号或机器路径。

历史财务/预测曲线与当前公开仓原图逐值比较：不引入新供应商序列；股价回撤前35个点因窗口不足为空。最新财务展示值保留SEC/发行人/交易所来源，不发布FactSet原始返回。财务不是本次重新取数，原有截止日及未知项保持。

新的数值、全新来源和许可边界需要另行复核，导出器会拒绝与原公开图不同的历史数值。未取得的季度预测保持null。

## 验证与发布

6项针对性测试：文件哈希/发布白名单、引用闭合及公开财务来源、嵌套HTML打包、JSON转义、Streamlit页面执行、AI导航与旧入口替换。

浏览器检查覆盖历史卡联动、AI路线与分析表、场景步骤、财务来源以及来源筛选。实际上线状态以线上页面验收为准，测试通过不等于已经上线。
