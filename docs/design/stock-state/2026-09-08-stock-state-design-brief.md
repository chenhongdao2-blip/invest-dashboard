### F6 分市场设计（D7 的落地）

```
美股（季度指引，原生形式）
  g_cur    = 本季实际 / 去年同季 − 1
  g_guided = 下季指引中值 / 去年同季(下季) − 1
  一阶 = 指引中值 vs 发布前一致预期（高于 / 低于 Street）
  二阶 = g_guided − g_cur                     # 管理层在引导加速还是减速；不依赖一致预期
日本（年度会社予想，期中修正）
  一阶 = 本次予想 vs 上次（上调 / 未调 / 下调）；二阶 = 予想 vs 一致预期
中国 A 股：无收入指引（业绩预告只给净利润区间且触发才发）→ 兜底 F2 或 F1，图例标「非指引」

```

### 5.4 结论与边界

- **结论**：美股主口径若做基本面版，F6「指引 vs Street」比 F3 surprise 更贴近价格反应；且「略高于预期」在 2025–26 已不再被奖励，四态里的「引导加速 × 高于」应设更高门槛。
- **边界**（写进任何产品文案前先过 research-discipline）：样本是今天的链成员，有幸存者偏差；2026「指引略低」只 10 个样本；「门槛在抬」是观测不是预测；指引匹配窗口 ±2 天是 agent 定的，519/590 匹配率高但未逐条核；回测只用于选口径的**证据**，不用于挑染色（§3.1 纪律 1）。
