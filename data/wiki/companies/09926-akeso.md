# 康方生物 (09926.HK)

**Summary**: 源头创新型 biotech，核心资产 **ivonescimab（依沃西单抗 / AK112）= 全球首创 PD-1×VEGF 双特异性抗体**；海外权益（美/欧/日等）授权 **Summit Therapeutics（NASDAQ: SMMT）**。肺癌 1L 多线 HARMONi 系列试验为价值主轴。

**Thesis**: PD-1/VEGF 双抗这条新通路已被 ivonescimab"打开一道缝"——HARMONi-2 头对头胜帕博利珠单抗（PFS）后，**HARMONi-6 已读出 OS 阳性（HR 0.66）**，从"PFS 优势"升级为"OS 获益"；若 Summit 美国 BLA（PDUFA 2026-11-14）+ HARMONi-3 全球读出落地，则补上"全球可及"。**核心变量 = PFS→OS 传导能否跨试验稳定成立 + Summit 海外执行/FDA**。

## 投资争议焦点：PFS → OS 传导

- 核心命题：H6 的 PFS 优势能否**传导至 OS**，并外推到 H2 / H3——一旦传导逻辑落定，估值锚从 PFS 切到 OS。
- 引用一位分析人士的「**五层 / 五维度传导**」框架（每层都成立才落实，概率问题）。来源 `[待核-未识别：转录"邓林社"]`。
- **化疗作用边界**：主要激发**初期 ORR**，对**长期 OS 获益**意义有限（类比历史 KEYNOTE 系列）——故 OS 长期分离才是机制信号。
- **关键数字纪律 ⚠️**：H6 实际 **OS HR=0.66**（ASCO 2026）；讨论中出现的 **0.72** 是读出前的怀疑锚点，**勿当结果引用**。
- 详见传导解读方法论 → [[clinical-topline-reading]]

## 风险点

- **PFS→OS 跨试验传导不确定**（核心 bear point）。
- **Summit 海外执行力 + FDA**：讨论者评 Summit 执行偏弱但速度快；"FDA 现场核查顺利"为讨论者口径，**独立确认待核**。
- **VEGF 类 class effect — 蛋白尿**（ivonescimab ~31.5%）等安全性。
- **中美 license / 政策审视**：私营 license 不在 BIOSECURE 覆盖，但国会有 broader scrutiny 背景 → [[coins-act-china-biotech-decoupling]]。

## 竞品 / 通路格局

- **信达 IBI363**：⚠️ 靶点 **PD-1/IL-2α-bias（不是 PD-1/VEGF）**，与 ivonescimab 是**机制类比**（同 PD-1 基础双功能、同挑战帕博利珠单抗），非同靶点；2026 ASCO 1L NSCLC+化疗 PoC 阳性、RCT II 期 vs 帕博+化疗在研（Takeda/TAK-928）。详见 [[01801-innovent]]。
- **Trop2 ADC** 等今年到读出的竞品 `[待核-未识别：转录"暖超爱"/"博泰"/"264"]`。
- **KOL 偏见争议**：现场部分专家以 >75 岁亚组等带主观 bias 质疑；讨论者强调 H6=随机双盲头对头，患者类型不应成为否定理由。
