# IPO 打新 day-1 Alpha 归因复盘

## 0. 触发问题
现有 6 因子质量打分卡 vs 首日收益 **Spearman ρ = +0.13 (p=0.61)** —— 对 day-1 几乎零排序力。
首日收涨率 15/17 = 88%、中位 +87% 是 **beta**（2026H1 港股科技/18A 打新普涨 regime）。
问题：什么因子能事前排出 +384%(曦智) / +266%(深演) / -4.6%(馭勢) / +0.6%(迈威) 这 ~390pct 的跨度？

## 1. 核心 thesis（三路收敛）
**Day-1 alpha 几乎完全来自 IPO 一级市场微观结构（"谁能买到票 + 票有多稀缺"），而非公司质量（"公司值多少钱"）。两者在本窗口近乎正交。**

最强反例 = **迈威生物**：pipeline 全队列第一（Nectin-4 ADC P3 / FDA FT×3 / BTD / 4款商业化 / 君实+药明基石），首日却近乎垫底 +0.6% —— 唯一原因是 **A+H 二次上市被 A 股价格锚死**。质量被结构一票碾压。

## 2. v-next 首日排序卡（factor card）

| 因子 | 动作 | 可靠性 | 说明 |
|---|---|---|---|
| **上市结构闸门 (A+H/二次上市 vs 纯H)** | **ADD（硬闸门/一票否决）** | HIGH | 2个A+H(迈威+0.6/可孚-1)是仅有的两个扑街；4个纯H首发全 +76~+179%。A股价格锚封顶上行 |
| **绝对自由流通盘 = 公开发售集资净额 HK$ (log, 反向)** | **ADD（主因子）** | HIGH | 挤兑的分母。深演5033万/+266 vs 华勤45.5亿/+13 单调。**必须用绝对额而非 free-float%**（18C回拨把热门股%系统拉到20%，%失去区分度）|
| **国配超购倍数 × 盘子 交互** | **ADD（非线性）** | HIGH | 机构真金白银去伪。小盘×低国配=挤兑暴涨(深演3.41x)；大盘×低国配=承接不足高开低走(可孚3.4x破发) |
| **赛道二级锚（同赛道已上市可比是否破发）** | ADD（时点闸门） | MED | 馭勢唯一亏损的决定性因子：L4(小马/文远/禾赛)招股时全线破发→"没有更大傻瓜" |

| **公开发售超购倍数** | **DOWNWEIGHT** | HIGH | 用户原4因子核心，**被证伪为单因子**：馭勢4666x(全行第二高)破发、商米2006x+241%。普涨里人人>1000x，区分度被β压平 |
| 题材"第一股"稀缺溢价 | DOWNWEIGHT | LOW | 疑似经超购中介（非独立），与盘子/超购共线。待正交检验 |
| **公司质量6因子卡** | **DROP（迁出首日卡）** | HIGH | ρ=+0.13无显著性。迁移到"破发回归/中长期持有"卡——不是无用，是用错时间维度 |

## 3. 可证伪回测 spec（防过拟合硬约束）
- **目标变量**：首日收盘收益率，用 **Spearman rank IC**（非 Pearson——右偏厚尾，曦智+384会主导）
- **降维纪律**：17样本只允许 ≤3 自由度。**禁止9因子大回归**。分层证伪：
  - Step1 单因子 IC + 排列检验 p（无自由度消耗）：|IC|≥0.45 且 p<0.10 保留
  - Step2 A+H 哑变量做 Mann-Whitney U 分组检验（闸门非连续因子）
  - Step3 最小模型 ≤3 因子：`day1 ~ A+H哑 + log(公开集资净额) + log(国配超购)`
  - Step4 **留一交叉验证(LOO)**：样本外 IC 衰减 >50% → 判过拟合
- **n-target ≥ 30**（当前仅 3 个非暴涨负样本，严重不足）。n<30 前因子权重只给 HIGH/MED/LOW 三档定性，**禁落任何回归系数**
- **证伪条件**：若机制三因子最小模型 LOO IC 也 <0.15 → thesis 被推翻，回到"打新无alpha、只配置β"

## 4. Top 3 立即动作
1. **零建模上线 A+H 硬闸门**：所有新股先打 A+H/二次上市标签 → A+H 一律首日降级回避。HIGH可靠、二元清晰、零自由度、最高 ROI
2. **首日卡换装"机制四因子"**（结构闸门 + log公开集资净额反向 + log国配超购×盘子 + 赛道二级锚），质量卡迁出首日、改用于持有期
3. **先跑 Step1单因子IC + Step4 LOO，再扩样到 n≥30**（重点补 A+H/破发负样本），之前只给三档定性权重

## 5. Open risks（头号=过拟合）
1. **过拟合**：17样本仅3个非暴涨负样本，9候选因子自由度严重不足。88%普涨使正样本几乎无信息量
2. **因子共线/中介混淆**：小盘×高超购×第一股×无A+H 高度共线（深演同时占满），无法在17样本分离独立贡献。"第一股"很可能只是绝对盘子的伪表象
3. **Regime 依赖**：整套机制alpha建立在2026H1特定regime。β转负时"小盘+无绿鞋"从放大器变自由落体加速器，卡无 regime detection 层
4. **目标变量口径敏感**：收盘 vs 暗盘 vs 开盘结论可能不同（创想暗盘+70收+21）。实操若暗盘卖出需重测
5. **幸存者偏差**：17只为已上市，未含撤回/延迟发行
6. **质量卡DROP的过度反应**：ρ不显著≠永远无用，β转向/破发回归场景质量可能重新主导。仅限首日卡 DROP

## 6. ⚠️ 数据可靠性 caveat（待 /cccg 与人工复核）
- **基石占比 slot 风险**（参 learned skill `ipo-prospectus-field-disambiguation`）：归因引用的基石%（商米27%、曦智65%、华勤49.93%等）需确认是**占发售**还是**占总股本**——两者差 6-7 倍，曾让拓璞评分升错一档。核心 thesis（A+H闸门+绝对盘子）不依赖此精度，但基石因子入模前必须人工核口径
- 超购倍数/AH折让/首日收盘 = HIGH（招股结果公告+收盘口径）；"破发潮""第一股稀缺" = MED-LOW 单源叙事，需 cross-validate
- 部分 day1_ret 混了两个来源（CMSI棱镜后测卡 vs 富途首日收盘），口径未完全统一

# 7. /cccg 四方对抗结论（v2 修订 · 2026-06-01）

四方 = Claude(原归因) + Codex(统计严谨) + Gemini(可操作/遗漏因子) + GLM(国内机制)。**三个外部 advisor 各自独立打出 BLOCKER，且高度收敛。**

## 7.1 总判决
**整套结论从"已验证的 alpha 因子卡"降级为"假设集(hypothesis set)"。** 在 n=17、仅 3 个非暴涨负样本下，rank IC + LOO 只能做 sanity check，不能当验证（Codex/Gemini 一致 [BLOCKER]）。当前唯一可立即落地的不是任何打分，而是几个 red flag + 一条数据采集 pipeline。

## 7.3 各 advisor 独家命中（盲点互补）
- **GLM（国内机制，最高价值）**：① 国配超购倍数港股**不强制披露**(只定性"适度/显著超额")→"国配×盘子"主因子无稳定数据源，须换孖展/国配认购额代理 ② 回拨机制理解错(超购>100x→公开回拨到50%，这部分恰恰**是**自由流通盘) ③ 集资净额漏老股转让(售股股东=首日最坚决砸盘筹码)+基石6个月锁定+绿鞋15% ④ 馭勢 peer 不是纯港股 L4。
- **Codex（统计）**：① n=17 + LOO 不能验证，只能假设生成；做 jackknife（删深演/馭勢/可孚看结论崩不崩）② 幸存者偏差(漏失败发行)③ 3 agent 收敛≠统计证据(看同一批数据，非独立)④ peer 必须预注册防事后挑选。
- **Gemini（可操作）**：① 必须 ADD 基石占比(锁70%货源则总盘10亿也流通极小)② ADD 定价区间位置(下限定价=让利=首日更易涨)+保荐人左席声誉 ③ 缺 sizing/退出层(孖展决策+10:30止盈，微结构alpha 10:30前消散)④ 残差回归剥离 size 后看国配是否还独立 ⑤ A股打新完全不适用(制度抹平)。

## 7.5 修订后回测纪律（在原 spec 上叠加）
1. **降级表述**：当前结果标"假设生成"，禁称"验证通过"
2. **共线先于归因**：先算因子相关矩阵(连续Spearman/二元point-biserial/Cramér's V)+残差回归(剥离 size 后看国配/第一股是否还显著)，否则禁止声称单因子独立有效→改用"因子簇"(供需簇/二级锚簇/价格锚簇)
3. **jackknife influence**：逐一删深演/馭勢/可孚/迈威/华勤，看结论是否崩溃
4. **幸存者偏差**：建 IPO funnel(递表→聆讯→招股→定价→上市/撤回)，拆两层模型(申购决策含失败发行风险 vs 已上市day-1排序)
5. **peer 预注册**：上市前固定 peer selection rule，禁事后增删
6. **目标变量拆 4 个**：暗盘/开盘/收盘/open-to-close，每因子出敏感性表
7. **门槛收紧**：n≥30 才滚动 rank IC，n≥80 才谈多因子交互/边际贡献

## 7.6 立即可执行（不需建模、零自由度）
1. **A/H red flag**（不是 veto）：新股先打 A+H/二次上市标签 + 算 H/A 折价率，折价<15% 重罚
2. **同业30天破发率闸门**：peer 预注册，>60% 破发强制回避
3. **搭数据采集 pipeline**：孖展倍数(招股截止前1-2天可得)+暗盘+A股同业前日表现——这三个比已上市因子更前置、可得性 HIGH，是真正能事前观测的信号
4. 先别落任何回归系数；把 17 样本当假设，去补 2023-2026 历史 A+H/二次上市样本验证"价格锚"先验
