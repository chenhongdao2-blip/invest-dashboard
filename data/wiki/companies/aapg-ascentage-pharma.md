# 亚盛医药 Ascentage Pharma (AAPG / 6855.HK)

**Summary**: 中国/全球商业化阶段创新肿瘤药公司（NASDAQ: AAPG；HKEX: 6855），专注凋亡通路和激酶靶点；核心商业化产品：olverembatinib（HQP1351，BCR-ABL 抑制剂，三代 TKI，已在中国获批），lisaftoclax（APG-2575，Bcl-2 抑制剂）；管线涵盖 MDM2-p53 抑制剂（alrizomadlin）、BTK PROTAC（APG-3288）等多条全球注册性 Phase 3 研究。

**Thesis**（卖方/产业叙事，非本人结论）:
1. Olverembatinib 在 T315I 突变 CML 中疗效突出，在不含 T315I 突变的一线 TKI 耐药/不耐受患者中亦显示高 MMR/CCyR 率；POLARIS-2 等 Phase 3 注册性研究持续推进，中国+全球双市场布局
2. Lisaftoclax（APG-2575）Bcl-2 抑制剂针对 CLL/SLL 及其他血液肿瘤，GLORA/GLORA-4 全球 Phase 3 进行中，与 BTK 抑制剂联用方案对标 venetoclax
3. ASCO 2026 获三项口头报告（rapid oral），数据覆盖白血病、肉瘤、儿童复发/转移性肉瘤，显示管线广度；APG-3288 FDA IND 获清，标志美国临床启动

- **POLARIS-2（olverembatinib CML Phase 3）**: 进行中，读出时间线 [待补]
- **GLORA / GLORA-4（lisaftoclax CLL/SLL Phase 3）**: 全球注册性研究进行中 [待补时间线]

## 风险点

- 中国 VBP（带量采购）对 olverembatinib 定价和利润率的潜在压力
- Bcl-2 抑制剂赛道 venetoclax（AbbVie）已深度渗透 CLL/SLL 市场，lisaftoclax 的差异化临床证据需要头对头数据支撑
- 多条全球 Phase 3 同时推进的资金压力
- 中美地缘政治风险对美国市场准入和跨境合作的潜在影响
