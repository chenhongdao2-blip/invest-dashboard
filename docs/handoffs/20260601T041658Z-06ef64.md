## 3. 关键决策
- **IPO 策略走独立 render**，不套现有 3 个策略的 `render_strategy`/`compute_strategy_returns`/yfinance：它是**静态截面快照**（评分 vs 首日%），非时间序列累计收益；首日定格不实时更新（George 明确要的）。
- **首日% = (首日收盘 − 发行价)/发行价**。拓璞 7688、馭勢 1511 用 futu **最终收盘**修正了 seed 的盘中值（拓璞 +32.5%盘中→+80%收盘；馭勢 −0.03→−4.6%）。深演 2723 区间定价由 iFind 确认顶格 55.5。
- **盘中小图归一化到发行价**（非开盘首 bar=100）：每条线终点 = 标题首日%、色按收盘正负——修了旧版「线方向与标题首日%矛盾」（George 实测反馈）。
- **散点破发点 = 档位色 + 红圈**（不再用红色盖掉档位色）——/cccg 3/3 一致 BLOCKER（馭勢是推荐档却被染红 = 像"推荐了破发股"）。
- **评分用截图的加权总分**（非 scorecard JSON 里的单因子分，如华曦达 JSON 9.0 其实是因子①、加权总分 5.9）；**universe = 正式打过分的 18 只**（不含 recap 里只观察没打分的智谱/MiniMax 等）。
- **KPI 配色**：红标签(CMSI_RED) + teal 数值(正收益，最高首日用 UP_DEEP) + ink(样本数) —— 因 inline `style` 被 Streamlit HTML 消毒器剥掉，必须用 CSS class（见 §4）。
