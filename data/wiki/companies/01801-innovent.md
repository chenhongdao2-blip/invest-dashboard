# 信达生物 Innovent Biologics (01801 HK)

**Summary**: 中国领先 biopharma，肿瘤为核心 + 代谢（mazdutide/IBI362 GLP-1/GCGR）双引擎；正以"借力顶级 MNC + 自身投入"模式加速全球化。核心肿瘤资产 IBI363（PD-1/IL-2α-bias 双特异性融合蛋白）在免疫耐药（IO-resistant）肺癌后线显示长拖尾 OS 优势；2026-05-28 与辉瑞达成总额至多 $10.5bn、覆盖 12 个分子的全球肿瘤战略合作（co-co 2.0）。

**Thesis**: ① IBI363 是高度差异化（well-differentiated）IO 新骨架，免疫耐药后线相对 docetaxel OS 优势明显、长拖尾效应明确，且数据外推至海外（吸烟比例更高人群）反而更有利；② 全球化 BD 验证：7 个月内 3 笔百亿美元级别交易，已与礼来/罗氏/武田/辉瑞四大 MNC 深度绑定，累计 5 个 co-co 核心项目、近 20 项全球合作管线；③ 财务确定性增强：国内业务高速增长、利润率持续提升，不含本次交易账上现金已逾 $4bn。

## 一、IBI363（PD-1/IL-2α-bias 双特异性融合蛋白）数据更新（CRO 周辉博士口径）

**适应症焦点**：免疫耐药（IO-resistant）非小细胞肺癌（鳞癌 + 腺癌），后线为主，正向一线推进。

### 关键临床数据（管理层口径，ESMO/ASCO 2026 长期随访更新）

| 指标 | 数值 | 备注 |
|------|------|------|
| 吸烟亚组 OS | 约 **23 个月** vs 对照 **11.5 个月** | 差异显著；吸烟为该适应症重要影响因素 |
| 24 个月 OS 率（3mg 剂量组）| 约 **47.8%**（接近 50%）| 相对 docetaxel 约 **3 倍**提升；KM 曲线分离明显 |
| vs 标准治疗 docetaxel（多西他赛）| OS、PFS 均明显延长；DOR 中位未达 | 信达自有随机对照（docetaxel 对照）结果与海外数据相近 |
| 安全性 | 主要为 IL-2(R) 通路相关关节痛、皮疹 | 与给药/暴露时间长相关；与既往披露差别不大；随经验积累发生率下降 |

- **人群差异 alpha（管理层强调）**：中国吸烟型腺癌比例明显低于西方；363 数据**外推至 global 反而更有利**（海外吸烟比例更高 → 优势人群更多）。非吸烟人群亦有获益，仅幅度相对较低。剔除驱动基因突变人群后，腺癌可及比例与鳞癌已接近。
- **剂量策略（3mg→1.5mg priming/loading）**：起始给 100µg 低剂量 prime 帮助耐受；prime 保护作用主要在第一周期（很多 AE 与 Cmax 相关）。基于安全性 + 机制（一次刺激即足够、起效后低剂量维持），最终采用单一 loading dose → 1.5mg 维持。一线将做同样评估，若典型适应症验证一致则全面铺开。**后线维持现剂量（3mg）不变**，研究者可按需降至 1.5mg（flexible）。
- **一线定位思路**：先与化疗联合做对照（认识最充分），以判断优势人群（鳞/腺、PD-L1 <1–49 vs ≥50）；363 与内部 ADC 管线联合也在推进，化疗联合经验可快速复用到 ADC 联合。
- 正在进行一项**全球随机多中心研究**（试验代号 ASR 糊，待核）。

> ⚠️ ASR 待核（勿作事实直引，对照音频/ESMO 摘要）：试验代号"临海"、"临安(3mg组)"、安全性对比对象"DGM"、IL-2(R) 写法"白JR"、"献爱"(疑鳞癌/吸烟)、一线引用试验 HARMONY-6 / OPTIMISM-05、FXCPT。

## 二、辉瑞（Pfizer）全球肿瘤战略合作（CBO Samuel Zhang 口径 + PR 核对）

**性质**：global licensing + co-development + co-commercialization，覆盖 ADC（差异化 payload）+ multi-specific 抗体。

### 财务与结构（PR 为准，HIGH）

| 项 | 数值 | 来源 |
|----|------|------|
| 首付款 | **$650M** | PR + 电话会管理层确认 |
| 里程碑（开发/注册/商业化）| 至多 **$9.85bn** | Pfizer PR 2026-05-28 |
| **总额** | 至多 **$10.5bn** | Pfizer PR 2026-05-28 |
| 销售分成 | 各许可产品 double-digit royalty | Pfizer PR |
| 分子数 | **12 个**（8 个信达自研早期 + 4 个辉瑞 discovery）| Pfizer PR |
| 交割 | 预计 **2026 Q3**（待监管批准）| Pfizer PR |

### 三种模式（管理层口径，各 4 个 = 12 个分子）

1. **4 个关键项目**：全球共同开发 + 美国与欧洲共同商业化、共享利润（最具战略意义；约 1/3 为 hard co-co arrangement）。
2. **4 个项目**：授予辉瑞大中华区以外权益，辉瑞承担绝大部分开发成本，信达获 milestone + royalty。
3. **4 个项目**：授予辉瑞全球独家许可权，辉瑞承担全球开发成本，信达获 milestone。

### 管理层叙事（"三个开创第一"）

- ① 单一治疗领域产品数量最多（12 个）；② 同一战略合作中 co-co 产品数量第一（4 个）；③ co-co 产品开发阶段特别早（如 IBI363 已完成 clinical proof-of-concept、进入/即将进入三期）——通常 MNC 仅在晚期才做 co-co。
- 双方在 **'IO + ADC'** 理念高度契合；辉瑞肿瘤深耕 20 余年（2003 收购 Pharmacia；近期 $430 亿收购 **Seagen**），ADC 领域开拓者。
- 信达称已建成全球第一个 dual-payload（双载荷）平台 [待核平台名]，并在 multi-specific（含 T-cell engager）有积累。

### 会计处理（CFO Rachel You 口径）

- $650M 首付处理与此前**武田、礼来**交易相似，预计未来约 **1–2 年后陆续摊销**；交易签署后信达仍负责所有分子的国内一期临床（非"收钱不参与"）。
- 12 个分子（含 4 个 co-co）多处于临床前早期；licensing 分子需承担研发费用很低，co-co 分子的 $650M 首付可支撑后续进入高成本 MRCT 三期的海外开发支出。进入全球三期仍需数年；公司对 funding 有信心（账上现金 > $4bn）。

## 四、全球化 BD 网络与管线梯队

- 近 **7 个月达成 3 笔百亿美元级别全球战略合作**，均居全球交易前十。
- 已与 **礼来（Lilly）/罗氏（Roche）/武田（Takeda）/辉瑞（Pfizer）** 四大顶级 MNC 深度绑定；累计落地 **5 个 co-co 核心项目** + 近 **20 项**全球合作管线（与礼来已是第七次合作）。本次称为 **"co-co 2.0"**。
- 利润分享 territory 由传统美国市场扩展至 **欧洲 + 美国**，覆盖单一药物全球 **80%+** 市场规模。
- 管线梯队：**IBI363** 领衔（肺癌/肠癌等五大适应症，对应市场逾 **$40bn**）；**IBI343、IBI324** 已/即将进入三期；叠加年初与礼来源头创新合作，形成 "3+1" + 自研模式，构成 20 余个项目的全球化肿瘤研发梯队。
- 长期目标：成为世界一流的创新药企业。

## 催化剂

- **IBI363 PFS 成熟数据**（管理层称下一次国际大会更新）——后线/一线 PFS 是关键，本次仅 OR 成熟。
- **辉瑞交易 2026 Q3 交割**（待监管批准）——确认 $650M 首付到账与摊销启动。
- IBI363 一线开发路径明确（化疗联合 → ADC 联合）+ 优势人群定位（PD-L1 分层 / 鳞-腺）。
- IBI343 / IBI324 进入三期里程碑。
- 海外首个分子上市/销售（管理层中长期信心点）。

## 风险点

1. **临床执行**：IBI363 PFS 尚未成熟，后线/一线注册性数据存在读出风险；样本量偏小（关键剂量组二十余例）。
2. **安全性**：IL-2 机制相关关节痛/皮疹，需依赖管理经验积累控制。
3. **交易/会计**：co-co 模式下需持续承担国内一期 + 后续 MRCT 海外开发支出，研发费用节奏受 co-co 分子推进影响。
4. **地缘**：中美 BD 政策噪音对中国资产对外授权的潜在影响（同业辉总曾被点名讨论，信达本次未直接评论）。
