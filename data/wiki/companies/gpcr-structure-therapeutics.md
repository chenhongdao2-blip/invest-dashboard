# Structure Therapeutics (GPCR)

**Summary**: 临床阶段 biotech，专注于基于 GPCR 结构生物学的小分子口服药物设计，核心资产 aleniglipron（GSBR-1290）是口服非肽类小分子 GLP-1 受体激动剂，Phase 2b ACCESS/ACCESS II 已读出强效减重数据，被市场视为 GLP-1 口服竞赛中最靠前的候选分子之一。

**Thesis**（卖方/产业叙事，非本人结论）:
1. ACCESS Phase 2b（36 周，120 mg）实现安慰剂调整后减重 11.3%（27.3 磅）；ACCESS II 探索性队列（240 mg，44 周）达 16.2%（40.5 磅），效果显著优于同类竞争分子，卖方普遍将其视为 Novo 口服司美格鲁肽的有力挑战者
2. 偏向 G 蛋白信号通路（biased agonist）设计理论上降低 GI 副作用风险，差异化技术卡位；口服剂型具有注射替代的市场渗透优势
3. 公司正在推进 Phase 3 启动准备，timeline 压缩意味着若 Phase 3 设计高效可在 2028-2029 年前完成注册

## 催化剂（临床读出/FDA/BD，带预期时间）

- **Aleniglipron Phase 3 设计与启动**: 2026 年内预期公布 Phase 3 方案，启动时间线是核心估值催化剂
- **ACCESS II 更长期随访数据（240 mg 44 周）**: 已呈现 16.2% 体重下降，进一步随访数据可强化 profile
- **其他 GPCR 靶点管线**: 公司持有多个 GPCR 靶点研究项目，具体管线 [待补]
- **潜在 BD 合作**: 凭借 Phase 2b 强数据，大型药企授权合作传闻持续，但尚无公告

## 风险点

- GLP-1 口服赛道竞争极激烈：Novo orforglipron（Phase 3 进行中）、Eli Lilly orforglipron 竞品、AZ/FHI 360 等均在追赶
- Phase 2b 样本量有限（约 220 人），Phase 3 规模扩大后疗效和安全性能否维持是关键不确定性
- 偏向 G 蛋白激动剂减少 GI 副作用的假设在 Phase 3 大规模人群中尚未验证
- 公司规模小、单一资产依赖度高，Phase 3 失败风险集中
- 与已上市 GLP-1 注射剂（司美格鲁肽、替泽帕肽）竞争时减重效果差距收窄
